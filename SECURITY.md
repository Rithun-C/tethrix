# Security

This is a personal learning project. It is not a product, and it runs for a limited time.

## Reporting a problem

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: on this repository, open the Security tab and
choose "Report a vulnerability". Only the owner can read the report.

Reports are read on a best-effort basis.

## What is in this repo

No secrets, keys, tokens or AWS account IDs are meant to be here. If you find one, that
is a security problem: please report it the same way.
